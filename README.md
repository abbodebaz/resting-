# Bayt Alebaa CX Demo

نموذج تفاعلي مقترح لنظام تقييم خدمات ما بعد البيع في **بيت الإباء** وربطه مع Odoo.

## هيكل المشروع

```text
resting-/
├── index.html
└── assets/
    ├── css/
    │   └── style.css
    └── js/
        └── app.js
```

- `index.html`: هيكل الصفحات والمحتوى فقط.
- `assets/css/style.css`: الهوية البصرية، التنسيق، والاستجابة للجوال.
- `assets/js/app.js`: التقييم، النجوم، الفلاتر، الإجابات والتنقل بين الواجهات.

## ما الموجود في النموذج؟

- صفحة تقييم عميل متجاوبة مع الجوال.
- تقييم نجوم محسّن مع أسئلة تفصيلية.
- ظهور أسباب عدم الرضا تلقائيًا عند التقييم المنخفض.
- صفحة إجابات العملاء مع البحث والفلاتر والتفاصيل.
- نموذج لإنشاء متابعة للتقييمات السلبية داخل Odoo.
- Dashboard للإدارة تشمل CSAT ومتوسط التقييم ومعدل الاستجابة وأسباب عدم الرضا ومقارنة المدن.
- تنبيهات ذكية مقترحة لاكتشاف انخفاض الأداء والمشكلات المتكررة.

## التشغيل

المشروع Static ومبني بـ HTML + CSS + JavaScript، ولا يحتاج Build أو Dependencies.

يمكن التنقل داخل النموذج بين:

1. صفحة التقييم
2. الإجابات
3. التقارير

> Prototype للعرض والتصور الأولي، وليس نسخة Production أو تكامل Odoo نهائي.
