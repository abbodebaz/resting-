# Bayt Alebaa CX Demo

نموذج تفاعلي مقترح لنظام تقييم خدمات ما بعد البيع في **بيت الإباء** وربطه مع Odoo.

## هيكل الصفحات

- `index.html` — مركز محاكاة تجربة ما بعد البيع.
- `survey.html` — صفحة تقييم العميل.
- `responses.html` — صفحة إجابات العملاء ومتابعة التقييمات.
- `reports.html` — صفحة التقارير والمؤشرات التنفيذية.

## الملفات المساندة

- `assets/css/style.css` — تصميم صفحات التقييم والإدارة.
- `assets/css/landing.css` — تصميم مركز المحاكاة.
- `assets/css/navigation.css` — التنقل المشترك بين الصفحات.
- `assets/js/survey.js` — منطق صفحة التقييم.
- `assets/js/responses.js` — منطق صفحة الإجابات والفلاتر والتفاصيل.

## التشغيل

المشروع مبني بـ HTML + CSS + JavaScript ولا يحتاج Build أو Dependencies. افتح `index.html` أو استخدم GitHub Pages للوصول إلى مركز المحاكاة ثم الانتقال إلى كل صفحة بشكل مستقل.

> Prototype للعرض والتصور الأولي، وليس نسخة Production أو تكامل Odoo نهائي.
